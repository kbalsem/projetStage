# Calculatrice_V2

## Description
Calculatrice_V2 est une application mobile Android réalisée en utilisant le framework Kotlin et l'architecture MVP. Elle permet aux utilisateurs de réaliser des calculs simples et complexes.

## Architecture
L'architecture du projet est basée sur le modèle-vue-présentateur (MVP). Cette architecture permet de séparer les responsabilités du code en trois couches distinctes : la couche de présentation, la couche de logique métier et la couche de données.

## Installation
Pour installer le projet, vous devez d'abord télécharger et installer Android Studio, l'environnement de développement intégré (EDI) officiel pour les applications Android. Une fois Android Studio installé, vous pouvez ouvrir le fichier `build.gradle` du projet et suivre les étapes d'installation.

## Utilisation
Pour utiliser le projet, vous devez d'abord installer l'application sur votre appareil mobile Android. Vous pouvez ensuite utiliser l'application pour réaliser des calculs simples et complexes.
